# v1.5.0 Release Cleanup — elo-estimator

## Context

The `multi-gpu` branch has 5 unreleased commits since `v1.4.0` (Nov 2025) covering substantial new surface: distributed multi-GPU processing with lock-file claims and `--start-index` resume, vast.ai/Docker support, JSON→Parquet/CSV converter for the downstream Jeff/Mark deliverable, and `check_errors.py` validator. Two independent audits surfaced doc drift, one real bug in `scripts/run_multi_gpu.sh`, stale version markers in three places, an untracked validator that's already documented, and assorted cleanup. The goal is a clean v1.5.0 cut: no schema or CLI breaks (1.5, not 2.0), README/CHANGELOG/VERSION reflecting reality, and the bug fix landed.

This plan was written in a prior Claude Code session that has now been cleared. To resume: read this file, read `CLAUDE.md` at repo root, and consult `~/.claude/projects/C--elo-estimator/memory/` for the collaboration/methodology context.

### C1 — Bug fix: `run_multi_gpu.sh` CWD bug

The script invokes `analyze_pgn.py` with no path prefix at lines 118 and 208. Fix with `$(dirname "$0")/analyze_pgn.py` so the script resolves its sibling regardless of CWD.
